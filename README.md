# 📦 Sistema de Control de Stock y Predicción de Demanda (Mini Market)

Aplicación web interactiva desarrollada con **Streamlit** y **Python** para la gestión de inventario, análisis de ventas y predicción de demanda en un mini market. El sistema permite visualizar el rendimiento comercial, registrar entradas y salidas de mercancía en tiempo real y detectar riesgos de faltantes de stock mediante el procesamiento de datos históricos.
